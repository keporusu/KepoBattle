# レベルエディタ 操作ガイド

Unity エディタの再生中に、レベル（ステージ）を配置・編集・保存するためのツールです。
作ったレベルは `Assets/StreamingAssets/Levels/` に JSON で保存され、そのままゲームに同梱されます。

- エディタは **Unity エディタ上でのみ** 動きます。ビルドしたゲーム（WebGL 等）では表示されません
- 設計の経緯や内部構造は [`DevDocs/LEVEL_EDITOR_DESIGN.md`](../DevDocs/LEVEL_EDITOR_DESIGN.md) を参照してください

---

## 1. 準備

シーンに次のコンポーネントが必要です（SampleScene は設定済み）。

| コンポーネント | 置き場所 | 設定 |
|---|---|---|
| `LevelManager` | 任意の GameObject | `Registry`: `Assets/ScriptableObjects/Level/LevelObjectRegistry.asset`<br>`Level File Name`: 読み込むレベルのファイル名（例: `SampleLevel.json`） |
| `LevelEditor` | 任意の GameObject | `Start In Edit Mode`: ON にすると編集モードで起動する<br>`Gui Scale`: 編集画面の拡大率（既定 2） |
| `CameraController` | Main Camera | `Offset`: カメラの位置のずらし（例: `(0, 1.54, 0)`） |

プレイヤー・敵・Prop・地形ブロックはレベルから生成されるので、**シーンには直接置かないでください**
（置くと二重になり、特にプレイヤーは2体とも同じ入力で動きます）。

### シーンでのプレビュー

再生していない時も、`Level File Name` のレベルが Scene ビューに表示されます（Hierarchy の `[Level Preview]`）。

- シーンには保存されず、Inspector からも編集できない一時的な表示です
- 再生を始めると消え、止めると表示し直します。レベルを保存した時も自動で更新されます
- メニュー **KepoBattle > レベルのプレビューを表示** で表示の ON / OFF、
  **KepoBattle > レベルのプレビューを更新** で手動で更新できます

## 2. 画面

再生すると、画面に次のウィンドウが出ます。

| ウィンドウ | 位置 | 内容 |
|---|---|---|
| レベル作成 | 左上 | モード表示・編集／再生ボタン（プレイ中はこれだけが出る）<br>編集中は、オブジェクト／地形の切り替え・吸着の切り替え・保存 |
| オブジェクト / 地形 | 左、その下 | 追加できるものの一覧（編集中のみ） |
| パラメータ | 右上 | 選択中のものの位置・パラメータ（選択中のみ） |

変更を保存していない間は、モード表示に「（未保存）」が付きます。

---

## 3. モード

### 編集モードとプレイモード

| ボタン | 動作 |
|---|---|
| 編集 | ゲームを止め、全てを初期配置に戻して編集できる状態にする |
| 再生 | 編集中の配置からプレイを始める |

- **保存していなくても、再生ボタンで今の配置をそのまま試せます**
- プレイ中の変化（爆発・落下など）は配置に影響しません。編集に戻ると、プレイ前の配置に戻ります
- プレイ中にプレイヤーが落下すると、レベル全体が初期配置からやり直しになります

### オブジェクトモードと地形モード（編集中）

| ボタン | 扱うもの |
|---|---|
| オブジェクト | Player・Enemy・Ball・Bomb・Spring |
| 地形 | 地形ブロック（Block_Normal） |

選択・範囲選択・追加できるのは、今のモードのものだけです。切り替えると選択は外れます。

---

## 4. 操作（編集中）

### 共通

| 操作 | 内容 |
|---|---|
| 左クリック | 選択 |
| Shift + 左クリック | 選択に追加 / 選択から外す |
| 選択中のものを左ドラッグ | 移動 |
| 何も無い所を左ドラッグ | 範囲選択（中心が範囲に入ったものを選ぶ。Shift で追加） |
| 何も無い所を左クリック | 選択を外す |
| D / Delete | 選択中のものを削除 |
| Esc | 選択を外す |
| 右ドラッグ / 中ドラッグ | カメラを動かす |
| スクロール | 拡大・縮小（プレイに戻ると元の大きさに戻る） |

- テキスト欄に入力中は、D / Delete などのキーは効きません（何も無い所をクリックすると入力が終わります）
- 選択しただけでは位置は変わりません。少しドラッグしてから動き始めます

### 追加

左の一覧のボタンを押すと、**画面の中央**に追加され、選択された状態になります。

### グリッド（マス目）

- 1マス = ワールド座標の 1（画面の縦がおよそ10マス）。編集中はマス目の線が表示されます
- **地形ブロック**: 常にマス目に揃います（ブロックの辺がマス目の線に乗る）
- **オブジェクト**: 「グリッドに吸着」が ON の間は、0.5マス刻みに揃います。OFF にすると自由に置けます

### 地形ブロックを増やす（地形モード）

**Command + 左ドラッグ**（Windows では Ctrl + 左ドラッグ）で、選択中のブロックを縦・横に並べて増やせます。

1. 増やしたいブロックを選択する（1個でも、複数でも可）
2. 選択中のブロックの上で Command を押しながらドラッグする
3. 緑の枠でプレビューが出るので、好きな数になったら離す

- 縦・横のうち、大きく動かした方向に増えます
- 選択中のブロックをひとまとまりとして、その大きさ単位で繰り返します
  （例: 縦3個の柱を選んで右にドラッグすると、柱が横に並ぶ）
- 既にブロックがあるマスには置きません
- 増えたブロックも選択に加わるので、そのまま続けて別の方向に増やせます
- 選択していないブロックから始めると、そのブロック1個だけを増やします

### パラメータ（右上のウィンドウ）

1つだけ選択すると、位置とパラメータを直接編集できます。変更はすぐ見た目に反映されます。

| 種類 | パラメータ | 内容 |
|---|---|---|
| Player | `facingRight` | 右を向いて始まるか |
| | `playerNumber` | 何Pか。**1P をカメラが追う**。プレイヤーを複数置くと、全員が同じ入力で動く |
| Enemy | `facingRight` | 右を向いて始まるか |
| Spring | `angle` | 向き（度）。0 が上向き、反時計回りが正 |
| Bomb | `fireOnSpawn` | 出現と同時に着火するか（編集中は着火しない） |
| 共通 | 位置 X / Y | 入力した値がそのまま使われる（吸着しない） |

複数選択している時は、移動と削除のみできます。

## 5. 保存

左上のウィンドウのファイル名の欄で名前を確認し、**保存** を押します。

- 保存先は `Assets/StreamingAssets/Levels/<ファイル名>` です。拡張子 `.json` は省略できます
- 同じ名前のファイルがあると、**確認なしで上書き**します
- 別の名前にすると、別のファイルとして保存されます（今のファイルはそのまま残る）
- 保存されるのは初期配置です。プレイ中に保存しても、プレイ中の状態は含まれません
- 保存した後、再生を止めると Scene ビューのプレビューも新しい配置になります

## 6. 新しいレベルを作る

今はエディタに「新規作成」「開く」がないため、次のどちらかで作ります。

### 方法1: 既存のレベルを別名で保存する（おすすめ）

1. 元にしたいレベルを読み込んだ状態で、編集モードにする
2. ファイル名の欄を新しい名前（例: `Stage1`）に変えて保存する
3. 再生を止め、`LevelManager` の `Level File Name` を `Stage1.json` に変える
4. 再生し、不要なものを消して作り込み、保存する

### 方法2: 空のレベルを手で作る

`Assets/StreamingAssets/Levels/` に次の内容の JSON を作り、`Level File Name` に指定します。

```json
{
  "version": 1,
  "settings": {
    "cameraMin": { "x": -6.6, "y": -4.0 },
    "cameraMax": { "x": 6.6, "y": 0.7 },
    "killHeight": -10.0
  },
  "objects": []
}
```

- ファイルが存在しないと読み込みに失敗し、エディタも表示されません
- プレイヤーを1体以上置いてください（いないとカメラが追う相手がいません）

### レベル全体の設定

次の設定はまだエディタで編集できないため、JSON の `settings` を直接書き換えてください。

| 項目 | 内容 |
|---|---|
| `cameraMin` / `cameraMax` | カメラが動ける範囲（カメラの中心をこの範囲に収める） |
| `killHeight` | これより下に落ちると、プレイヤーはレベルをやり直し、敵・Prop は消える |

---

## 7. 新しい種類のオブジェクト・地形ブロックを追加する

1. Prefab を作る
    - 地形ブロック: ワールド上で **1×1** の大きさになる Scale にする。Layer `Ground`、Tag `Geometry Channel`、Collider は isTrigger。回転させない
2. `Assets/ScriptableObjects/Level/LevelObjectRegistry.asset` に追加する
    - `Key`: レベルデータに書かれる種別名。**一度使ったら変えない**（変えると、そのキーで保存したレベルが読めなくなる）
    - `Category`: `Object` か `Terrain`
    - `Prefab`: 作った Prefab
3. 固有のパラメータを持たせたい場合は、コンポーネントに `ILevelObject` を実装する（パラメータの欄に自動で並ぶ）

---

## 8. できないこと・注意点

- 元に戻す（Undo / Redo）はできません。こまめに保存してください
- 地形ブロックを動かした先に既にブロックがあると、重なります（増やす時だけ重複を避けます）
- 複数選択時のパラメータの一括編集はできません
- レベルの「新規作成」「開く」、レベル全体の設定の編集はエディタ上ではできません（6章を参照）
